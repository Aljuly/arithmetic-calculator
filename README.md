# 🧮 Arithmetic Calculator

A Spring Boot backend with an Angular frontend.

| Module | Description |
|---|---|
| [`calculator-backend/`](calculator-backend/README.md) | Spring Boot REST API: registration, email verification, password management, JWT + 2FA |
| [`calculator-frontend/`](calculator-frontend/src/main/web/README.md) | Angular 10 single-page app |
| [`docker/`](docker/docker-compose.yml) | Docker Compose for PostgreSQL, the backend and the Nginx-served frontend |

See each module's README for setup and usage.
